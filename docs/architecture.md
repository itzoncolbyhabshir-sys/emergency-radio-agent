## 4. 关键设计决策

### 4.1 异步队列解耦

音频采集在独立线程运行(受 sounddevice 限制),通过 `asyncio.run_coroutine_threadsafe` 将事件投递到主事件循环的队列中,WebSocket 广播从队列消费。

### 4.2 事件去重

3 秒内相同内容不重复推送,基于文本前 20 字符的 hash。防止对讲机重复呼叫导致大屏刷屏。

### 4.3 自动降级

```
GPU available ──▶ medium + int8_float16
    │
    ▼ fallback
CPU available ──▶ small + int8
    │
    ▼ fallback
Mock mode ──────▶ 预设响应轮询
```

### 4.4 LED 墙适配

- CSS 变量控制字号缩放比例
- 使用 `vw/vh` 单位自适应分辨率
- 纯黑底 `#000` 避免 LED 低亮度发灰
- 粗边框(3px+)替代细线
- 动画时长 0.6s+,避免高刷新率闪烁

## 5. 性能基准

| 环节 | 耗时 | 优化手段 |
|------|------|----------|
| SDR 解调 | <100ms | 硬件实时 |
| VAD 切片 | 450-750ms | silence threshold=15 帧 |
| Whisper medium | 0.8-2s | CTranslate2 + int8_float16 |
| 分类引擎 | <50ms | 纯内存字典匹配 |
| WebSocket | <16ms | 本地局域网 |
| **总延迟** | **1.5-3.5s** | 端到端 |

## 6. 安全考虑

- 所有处理本地完成,无云端依赖
- 语音片段自动清理(可配置)
- WebSocket 无认证(Demo 阶段)
- 频率使用遵守当地法规
