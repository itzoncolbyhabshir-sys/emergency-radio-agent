# 应急无线电台智慧中枢 - Windows 迁移说明

这个包用于把当前演示工程迁移到另一台 Windows 电脑。包内已经包含：

- 后端 FastAPI 服务源码与当前演示数据库
- 前端源码与已经构建好的 `frontend/dist`
- 上海离线地图与高德在线地图配置
- SDR 相关工具目录，包括 Zadig/SDR++ 工具文件
- 一键安装依赖和启动脚本
- 演示截图与测试素材

## 1. 推荐环境

- Windows 10/11
- Python 3.10 或 3.11（如 3.13 安装依赖失败，建议换 3.10/3.11）
- Node.js 18+
- RTL-SDR 设备：需用 Zadig 安装 WinUSB 驱动
- 如需 GPU Whisper：需要 NVIDIA 显卡、CUDA 环境；否则可先用模拟模式演示

## 2. 首次安装

在项目根目录打开 PowerShell，先允许本次窗口执行脚本：

```powershell
Set-ExecutionPolicy -Scope Process Bypass
```

然后安装依赖并重新构建前端：

```powershell
.\install_dependencies.ps1
```

如果目标电脑不能联网，需要提前把 Python 包、npm 缓存、Whisper 模型缓存也复制过去；本迁移包不包含大型模型缓存。

## 3. 启动真实 SDR 演示

先确保 SDR++、SDR# 或其它接收软件已经关闭，否则 RTL-SDR 设备会被占用。

```powershell
.\start_backend_rtlsdr.ps1
```

默认监听频率为 `409.7500 MHz`，启动后打开：

```text
http://127.0.0.1:8000/#/
```

如果需要改频率，可在启动前设置：

```powershell
$env:RTL_FREQUENCY_MHZ="430.0000"
.\start_backend_rtlsdr.ps1
```

## 4. 无 SDR 的保底演示

如果新电脑暂时没有 SDR，或者现场设备被占用，可以先用模拟模式保证大屏可演示：

```powershell
.\start_backend_mock.ps1
```

然后打开：

```text
http://127.0.0.1:8000/#/
```

## 5. 前后端开发模式

如果需要边改前端边演示，可以开两个 PowerShell 窗口：

窗口一：

```powershell
.\start_backend_rtlsdr.ps1
```

窗口二：

```powershell
.\start_frontend_dev.ps1
```

然后访问：

```text
http://127.0.0.1:3000/#/
```

## 6. 地图与密钥说明

`frontend/.env.local` 中包含当前高德 Web API Key，用于在线地图演示。这个 Key 会暴露在前端，请在高德控制台限制可用域名/IP，不要直接公开到公共仓库。

如果新电脑没有网络，大屏会自动使用内置上海离线地图。

## 7. 常见问题

### 设备提示 cannot open RTL-SDR

通常是 SDR++、SDR# 或其它程序占用了设备。关闭其它接收软件后重新运行启动脚本。

### Zadig 驱动

打开：

```text
tools\sdr\zadig-2.9.exe
```

选择 RTL-SDR 设备并安装 WinUSB 驱动。

### Whisper 首次运行慢

第一次运行真实语音识别时可能下载/加载模型。演示前建议先启动一次，等模型加载完成。

### 只想快速录屏

优先用：

```powershell
.\start_backend_mock.ps1
```

确认大屏、地图、事件流、语音复核列表都能显示后，再切换真实 SDR。
